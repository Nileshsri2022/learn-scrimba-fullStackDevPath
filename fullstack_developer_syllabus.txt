SCOPE
------------------------------------------------------------------------
This syllabus is an ordered, repository-derived outline of the learning
activities included in the supplied Scrimba challenge-files repository. It
contains 20 modules, 85 top-level sections, and 1391
named sections, lessons, projects, and nested practice items after excluding
implementation assets (such as src, public, images, coverage, and duplicate original files).

The source repository contains challenge files rather than every video/scrim
in the hosted course. Therefore, gaps in lesson numbers indicate material that
has no corresponding folder in this repository; they are intentionally kept
rather than renumbered. Folder titles are retained as the source of truth.

HOW TO READ THE OUTLINE

• MODULE: a major course phase.
  SECTION / UNIT: a topic, build, project, or challenge collection within that phase.
    LESSON / ACTIVITY: a sequenced repository learning item.
      PRACTICE: an exercise nested under that activity.
